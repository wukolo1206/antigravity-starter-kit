# 新專案範本（備案用）

> 裝不了「新專案初始化」技能時，用這個資料夾開新專案。

## 使用方式
1. 把整個「新專案範本」資料夾**複製一份**，改成你的專案名稱（例：四上國語第三課評量）
2. 用 Antigravity 打開改好名字的資料夾
3. 對特助說：
   > 💬 「請依照 .agents/AGENTS.md 裡的【】提示問我問題，幫我把這個專案的說明便條、交接簿填好。」
4. 特助會問你專案名稱、要做什麼、給誰用、有沒有不能動的東西，然後把【】的地方填好

## 裡面有什麼
| 檔案／資料夾 | 用途 |
|---|---|
| `.agents/AGENTS.md` | 辦公桌說明便條：這個專案是什麼、檔案放哪、不能動的地方、收工要做什麼 |
| `handoff.md` | 交接簿：做到哪、下一步 |
| `CHANGELOG.md` | 版本紀錄：每完成一個新東西記一筆 |
| `PITFALLS.md` | 踩坑紀錄：遇到難搞的問題、怎麼解決 |
| `DECISIONS.md` | 決策紀錄：重要的選擇與原因 |
| `素材/` | 老師給的原始檔 |
| `產出/` | 特助做好的成品 |

⚠️ 任何紀錄檔都不要寫學生姓名、成績、密碼。
