# 新專案一鍵初始化（開辦一張新辦公桌）

老師開新專案時，一次把特助需要的字條和資料夾全部設好，之後每次打開這個資料夾，特助都知道這是什麼專案、做到哪裡。

## 步驟一：先檢查資料夾

1. 列出目前資料夾裡已有的檔案與資料夾。
2. **若已經有 `.agents/AGENTS.md`、`handoff.md`、`CHANGELOG.md`、`PITFALLS.md`、`DECISIONS.md` 其中任何一個：絕不覆蓋。** 告訴老師哪些已存在，只建立缺少的，並詢問老師是否繼續。
3. 若資料夾裡已有其他檔案（例如老師先放了課本 PDF），照常進行，不要移動或修改它們；最後再詢問老師要不要把它們搬進「素材」資料夾。

## 步驟二：問老師四個問題（一次問完，用編號列出）

1. 這個專案的名稱？（預設用資料夾名稱，直接按 Enter 或說「預設」即可）
2. 這個專案要做什麼？請用一句話說明。（例：四年級國語第三課的評量卷）
3. 做好的東西給誰用？（學生／家長／同事／自己）
4. 有沒有不能動的東西？（例：學校提供的名冊格式不能改；沒有就說「沒有」）

## 步驟三：建立檔案與資料夾

建立前，列出將要建立的清單，請老師核准（Approve）後再寫入。今天的日期用 YYYY-MM-DD 格式。

```
<專案資料夾>/
├── .agents/
│   └── AGENTS.md      ← 辦公桌說明便條
├── handoff.md         ← 交接簿
├── CHANGELOG.md       ← 版本紀錄
├── PITFALLS.md        ← 踩坑紀錄
├── DECISIONS.md       ← 決策紀錄
├── 素材/              ← 老師給的原始檔
└── 產出/              ← 特助做好的成品
```

### `.agents/AGENTS.md`（辦公桌說明便條）

```markdown
# 【專案名稱】

## 這個專案是什麼
【老師回答的第 2 題】

## 給誰用
【老師回答的第 3 題】

## 檔案放哪裡
- `素材/`：老師給的原始檔（課本、名冊、題本）。**不要修改原始檔**，要改先另存到 `產出/`。
- `產出/`：特助做好的成品。

## 不能動的地方
【老師回答的第 4 題；沒有就寫「目前沒有」】

## 特助每次工作的規矩
- 開始前：先讀 `handoff.md`，知道上次做到哪。
- 修改老師整理過的檔案前，先另存一份備份。
- 不寫入學生姓名、成績、密碼到任何紀錄檔。
- 老師說「收工」時：
  1. 更新 `handoff.md`（目前進度、這次做了什麼、下一步、注意事項）
  2. 有完成新東西 → 在 `CHANGELOG.md` 最上面加一筆
  3. 解決了不好找的問題 → 在 `PITFALLS.md` 最下面加一筆
  4. 做了重要的選擇（例如選了 A 版型不用 B）→ 在 `DECISIONS.md` 加一筆
  5. 列出這次改過的檔案，提醒下次從哪裡開始
```

### `handoff.md`（交接簿）

```markdown
# 交接簿 — 【今天日期】

## 目前進度
專案剛建立，還沒開始工作。

## 這次做了什麼
- 建立專案資料夾與紀錄檔

## 下一步
1. 把原始檔放進 `素材/` 資料夾
2. 告訴特助第一件要做的事

## 注意事項
- 【老師回答的第 4 題；沒有就寫「目前沒有」】
```

### `CHANGELOG.md`（版本紀錄）

```markdown
# 版本紀錄

> 每完成一個新東西，就在最上面加一筆：日期、做了什麼。

## 【今天日期】
- 建立專案：【專案名稱】
```

### `PITFALLS.md`（踩坑紀錄）

```markdown
# 踩坑紀錄

> 遇到不好找的問題、解決之後，記在這裡，下次就不會再踩。

## ⚠️ 還沒解決的問題
- 目前沒有

## 已經解決的問題
（第一次踩坑後，由特助在這裡新增：現象、原因、怎麼解決）
```

### `DECISIONS.md`（決策紀錄）

```markdown
# 決策紀錄

> 做了重要的選擇時記在這裡：選了什麼、為什麼、沒選什麼。之後改變主意時，把舊的劃掉（~~刪除線~~）再寫新的，不要直接刪掉。

（第一個重要決定後，由特助在這裡新增）
```

### 兩個資料夾
建立 `素材/` 與 `產出/`。

## 步驟四：完成回報

1. 用表格列出建立了哪些檔案與資料夾，每個一句話說明用途。
2. 提醒老師三件事：
   - 「請把課本、名冊等原始檔放進 **素材** 資料夾。」
   - 「開新對話問我『這個專案是做什麼的？』，可以確認說明便條生效。」
   - 「每次做完說『**收工**』，我會更新交接簿和紀錄。」

## 安全規則
- 絕不覆蓋已存在的檔案。
- 任何紀錄檔都不寫學生姓名、成績、密碼、金鑰。
- 寫檔前一律請老師核准（Approve）。
