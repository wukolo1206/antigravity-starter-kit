# Antigravity 課程懶人包 - 大腦自覺引導規則

這份檔案定義了 AI Agent 在此懶人包專案中的行為指引，旨在幫助老師一秒完成備課環境建置。

---

## 🚀 課程懶人包初始化規則 (課程設定)

**觸發條件**：
當用戶（老師）在對話中提及「**課程初始化**」、「**課程設定**」、「**環境設定**」或類似意圖時。

**大腦執行流程**：
1. **執行套件檢測**：
   - 主動在背景執行 `python setup.py`（這會彈出人機協同核准框，請引導用戶點選 `Approve`）。
   - 觀察執行結果，確認是否所有依賴套件（`python-docx`、`openpyxl`、`google-api-python-client`、`google-auth-oauthlib`）皆已安裝。

2. **金鑰存在性檢查**：
   - 自動調用檔案讀寫/檢測工具，檢查 `google workspace/` 目錄下是否存在實體 `credentials.json` 憑證。
   - 如果不存在，請友善提醒用戶：「老師，我發現您的 `google workspace/` 資料夾下還沒有 `credentials.json` 金鑰。請將下載好的金鑰放入該資料夾，我才能在後續課程中為您串接 Google 雲端喔！」

3. **回報專案就緒狀態**：
   - 執行完上述檢查後，請用 Markdown 表格向用戶回報初始化結果：
     * 🟢 Python 及依賴套件環境檢測狀態
     * 🟢 `google workspace/credentials.json` 金鑰就緒狀態
     * 🟢 預裝技能（`@doc_expert`、`@pdf`）載入狀態
   - 回報完成後，主動引導用戶雙擊開啟專案根目錄下的 `index.html` 網頁開始體驗一鍵複製 Prompt！

## 📒 實戰八：收工與交接簿（讓特助記得你）

### 收工
**觸發條件**：當用戶（老師）說「**收工**」、「**下班了**」、「**今天到這裡**」或類似意圖時。

**大腦執行流程**：
1. 在本專案根目錄寫入（或更新）`handoff.md`，格式照 `範本/交接簿_範本.md`：更新時間、目前進度、這次做了什麼、下一步、注意事項。
2. 寫檔前依安全防線請用戶 `Approve`。
3. 回報時列出這次改過或新增的檔案，並用一句話提醒下次要從哪裡開始。
4. 若用戶有全域主管交代手冊（`~/.agents/AGENTS.md`），把它和全域技能資料夾（`~/.agents/skills/`）備份到 Google 雲端硬碟的「AI特助備份」資料夾（通常是 `G:\我的雲端硬碟\AI特助備份\`）：手冊存成 `主管交代手冊.md`，技能放在 `skills\`。找不到雲端硬碟就跳過並提醒用戶。
4. **交接簿不可寫入**學生姓名、成績、密碼或金鑰內容。

### 讀取交接簿（開工）
**觸發條件**：當用戶說「**讀取交接簿**」、「**繼續上次的工作**」或類似意圖時。

**大腦執行流程**：
1. 讀取本專案根目錄的 `handoff.md`；若不存在，告訴用戶「這個資料夾還沒有交接簿，下次工作結束時說『收工』我就會寫一份」。
2. 用三行以內摘要：上次做到哪、下一步是什麼。
3. 詢問用戶是否照下一步繼續，得到同意才動手。

### 建立主管交代手冊
**觸發條件**：當用戶說「**建立主管交代手冊**」或類似意圖時。

**大腦執行流程**：
1. 先問五個問題：稱呼、任教年級與科目、希望的語氣、最常請你做的三件事、不希望你做的事。
2. 依 `範本/主管交代手冊_範本.md` 填好內容，寫入用戶的全域規則檔 `~/.agents/AGENTS.md`（若已存在，先備份為 `AGENTS.md.bak` 並詢問要合併還是取代）。
3. 寫檔前請用戶 `Approve`，完成後把內容顯示給用戶確認。
4. 同時把手冊備份一份到 Google 雲端硬碟「AI特助備份」資料夾的 `主管交代手冊.md`（找不到雲端硬碟就跳過並提醒用戶）。
4. 手冊中**不可寫入**密碼、金鑰、學生姓名與成績。

### 新電腦開工（換電腦時搬回手冊與技能）
**觸發條件**：當用戶說「**新電腦開工**」、「**換新電腦了**」或類似意圖時。

**大腦執行流程**：
1. 找到 Google 雲端硬碟的「AI特助備份」資料夾（通常是 `G:\我的雲端硬碟\AI特助備份\`）；找不到就請用戶確認已安裝並登入 Google 雲端硬碟電腦版，或告訴你資料夾位置。
2. 把 `主管交代手冊.md` 複製成 `~/.agents/AGENTS.md`；把 `skills\` 裡的每個技能資料夾複製到 `~/.agents/skills/`。
3. 若 `~/.agents/skills/project-init/SKILL.md` 仍不存在，從 https://raw.githubusercontent.com/wukolo1206/antigravity-starter-kit/main/.agents/skills/project-init/SKILL.md 下載安裝。
4. 這台電腦上已經存在的同名檔案：先備份為 `.bak`，再詢問用戶要不要取代。寫檔前請用戶 `Approve`。
5. 用表格回報：主管交代手冊、各技能是否就緒；提醒用戶開新對話問「我是誰？」確認手冊生效。
6. **不搬對話紀錄**：重要的事都在交接簿和手冊裡。

## 🔒 安全與開發防線

1. **修改與寫入安全**：
   - 當修改或建立任何 Word (.docx) 或 Excel (.xlsx) 檔案前，務必為用戶規劃好清晰的 ReAct 步驟。
   - 寫檔與執行終端命令前，必須停下來請求用戶 `Approve`，絕不在未經同意下在背景執行未知代碼。
2. **敏感資訊防護**：
   - 絕不將 `google workspace/token.json` 或 `credentials.json` 內容外流。
